Flood Zone Mapping Survey (Survey123)

This Survey123 application was designed to collect user-reported flood locations. It demonstrates interactive data collection, spatial input validation, and real-time geospatial data aggregation using ArcGIS Online. (Dynamic survey which adds questions based on the respondant. For example, will only prompt user to enter a photo if they have selected a point on the map which is not already in a flood zone.)

Improvements From Final Submission

  • Improved question layout and reduced user confusion in the frequency of flooding question.
  • Added new features measuring the depth, and length of an entered flood.
  • Improved data structure for downstream GIS analysis.
