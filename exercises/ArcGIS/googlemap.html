This interactive web map was built using the Google Maps JavaScript API. It visualizes key community locations across Weymouth, Braintree, and Quincy using categorized markers, custom icons, and interactive pop-up information windows.

Tools Used

Google Maps JavaScript API, custom JavaScript event handling, HTML/CSS layout design, and structured geospatial data visualization.

Improvements From Initial Submission

  • Expanded dataset to include additional public schools across Weymouth, Braintree, and Quincy.
  • Standardized marker icon sizing for visual consistency.
  • Improved popup contrast and readability.
  • Updated legend to reflect all feature categories.
  • Centered map intentionally for spatial focus instead of auto-fit bounds.
