Web GIS Portfolio

This portfolio showcases interactive Web GIS applications developed using ArcGIS Online, Survey123, and JavaScript-based mapping tools. Each project demonstrates spatial analysis, cartographic design, and user-focused interactivity, with revisions based on feedback and design improvements.

Flood Zone Mapping Survey

A Survey123 application designed to collect user-reported flood locations using an interactive geospatial survey interface.

Tools Used ArcGIS Survey123, ArcGIS Online, HTML/CSS
Key Features
  • Interactive survey input
  • Location-enabled submissions
  • Real-time spatial data collection
  • Mobile-friendly design
Design Improvements Improved layout structure, clearer form flow, and enhanced usability for mobile users.

Environmental Justice Map

An ArcGIS Online web map analyzing environmental justice populations and infrastructure access using layered spatial data.

Tools Used ArcGIS Online, ArcGIS Pro, HTML/CSS
Key Features
  • Interactive pop-ups
  • Layer-based analysis
  • Custom symbology
  • Comparative infrastructure mapping
Design Improvements Removed redundant information from pop-up windows. Adjusted naming of map layers. Updated name of popup to present more useful information (town and minority class designation). Added clarity to legend, pop-up information. Proper sourcing of the data used.
